# PHP OOP Fundamental
Studi Kasus : Sistem Pengelolaan Uang Kas Kelas 

# Penjelasan 
Pencatatan pembayaran uang kas mingguan oleh bendahara kelas saat ini masih
menggunakan buku tulis manual, yang menyebabkan pelacakan tunggakan siswa menjadi
lambat, rentan terhadap kesalahan perhitungan saldo, berisiko kehilangan data jika buku
rusak, serta kurangnya transparansi laporan keuangan bagi anggota kelas. Tujuan
pembuatan sistem pengelolaan uang kas untuk mendigitalisasi pengelolaan uang kas
sehingga pencatatan transaksi masuk dan keluar menjadi lebih akurat, aman, dan seluruh
siswa dapat memantau transparansi dana secara real-time (nyata).
